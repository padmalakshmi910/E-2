# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:

To design and implement a Library Management System using software engineering principles. The system should manage library operations such as book addition, book search, book issue, book return, member registration, and librarian/admin management.

# Procedure:

1. Analyze project requirements for a Library Management System based on real-world library functions.

2. Identify actors (e.g., Member, Visitor, Librarian, Admin) and relevant system use cases.

3. Document functional and non-functional requirements in an SRS.

4. Draw appropriate diagrams based on system flow (e.g., Use Case, Class, Sequence, Activity, Communication, and Package diagrams).

5. Select and justify suitable technologies and software tools for system implementation.

6. Design the user interface for easy book searching, issuing, returning, and member management.

7. Develop the backend logic to handle book records, member details, book issues, and returns.

8. Implement user authentication and authorization mechanisms for members, librarians, and admins.

9. Test the system for all supported library operations.

10. Verify correct handling of exceptions and edge cases (like unavailable books, invalid member details, and overdue books).
